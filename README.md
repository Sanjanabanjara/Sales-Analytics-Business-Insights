# Sales Analytics & Business Insights Dashboard

## Project Overview
An end-to-end Data Analytics project focused on analyzing sales performance, identifying business trends, and generating actionable insights using Python, SQL, Excel, and Power BI.

## Tools & Technologies
- **Python:** Pandas, Matplotlib
- **SQL:** SQLite
- **Excel:** Pivot Tables, Pivot Charts, Slicers
- **Power BI:** DAX Measures, Interactive Dashboards

## Project Objectives
- Analyze monthly and regional sales trends.
- Identify profitable product categories.
- Evaluate top-performing products.
- Build interactive dashboards.
- Provide data-driven business recommendations.
