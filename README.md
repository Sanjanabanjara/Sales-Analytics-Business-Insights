
# Sales Analytics & Business Insights Dashboard

## Project Overview

An end-to-end data analytics portfolio project
focused on analyzing sales performance, identifying
business trends, and generating actionable insights.

The project analyzes 1,000 transactions from a
synthetic sales dataset covering January–December 2025.

## Tools & Technologies

- Python: Pandas, Matplotlib
- SQL: SQLite
- Microsoft Excel: Pivot Tables, Charts, Slicers
- Power BI: DAX, Interactive Dashboards
- GitHub: Version Control and Documentation

## Project Objectives

- Analyze monthly sales and profit trends
- Evaluate regional and product performance
- Compare online and in-store sales
- Identify profitable product categories
- Develop interactive dashboards
- Generate data-driven business recommendations

## Key Business Findings

- October recorded the highest monthly sales:
  approximately INR 18.58 lakh.
- June recorded the lowest monthly sales:
  approximately INR 9.01 lakh.
- West was the top-performing sales region.
- Electronics generated the highest category profit.
- Online and in-store channels contributed
  almost equally to total revenue.

## How to Run the Project

### Python Analysis

1. Install Python 3.
2. Install dependencies:

```bash
pip install pandas matplotlib
```

3. Run the Python analysis:

```bash
python python_analysis/main.py
```

### SQL Analysis

Run:

```bash
python sql_analysis/sql_analysis.py
```

The SQL script creates a local SQLite database
from the CSV dataset and executes analysis queries.

### Dashboards

- Open the Excel workbook using Microsoft Excel.
- Open the `.pbix` file using Power BI Desktop.
- Dashboard screenshots are available in their
  respective GitHub folders.
