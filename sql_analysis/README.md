# SQL Sales Analysis

## Tools
- SQLite
- Python (sqlite3, Pandas)

## Analysis Performed
- Sales summary
- Region-wise sales
- Category-wise profit
- Monthly sales trends
- Top 5 products
- Sales channel analysis
- Payment method analysis
- Profit margin analysis

## How to Run
Run `sql_analysis.py` from the project.

The script reads the CSV dataset, creates a SQLite database, and executes 11 SQL queries.
